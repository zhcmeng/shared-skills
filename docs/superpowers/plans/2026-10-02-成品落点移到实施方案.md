**Goal:** 把测试用例规格说明里的「成品落点」整块搬进第七份《实施方案规格说明》的方案节，让六份通用稿不再出现成品路径与落成进度。

**Tech Stack:** Python 3（`check_docs.py`、`check_landing.py`、三份手写测试），bash（`checks/verify.d/90-test-case-design.sh`），Markdown 文档。

**Spec:** `docs/superpowers/specs/2026-10-02-成品落点移到实施方案-design.md`

## Global Constraints

- 块名照旧「成品落点」（`check_docs.PLACE_HEAD`），**不改**——脚本按标题里的词认块。
- 表头照旧两列：`成品` | `落的是哪些条目`（`check_docs.PLACE_COLS`）。
- 三种状态照旧：一句「还没落成」（**写在这一块里，不占表格**）／已落成的列成表／分批时两种并存。
- 这一块在方案节里排**最后一块**：编号落到哪 → 说明 → 怎么跑 → **成品落点**。
- 第七份每个方案节**都必须有**这一块；用例那份不再查它，还留着只报提示（不是错）。
- 成品路径按**跑命令时的当前目录**算（与命令行给路径同一个基准），不改成按评测材料根算。
- `check_landing.py` 退出码：`0` 对得上、`1` 有错、`2` 用错或表坏、`3` 没有可对照的成品（**第七份整份不在**、或这一块写着「还没落成」）。
- 版本号抬末位：`1.26.27` → `1.26.28`（`plugin/.claude-plugin/plugin.json` 与 `.claude-plugin/marketplace.json` 两处必须一致）。
- 正文写中文、全角标点、引号用「」；文件名一律英文（本计划新增的文件都是既有文件，不新增文件名）。
- 每个任务收尾要跑：`python tests/test-case-design/<改动到的那份>.py`（它自己打「N 例，M 处不对」并以退出码表态）。

## Review Focus

- **第七份里有第二个方案节时**：两节各查各的成品落点，第一节的表不能把第二节的算进来，反之亦然（切块切到下一个 `^#{1,3}` 而不是下一个 `^##`）。
- **第七份在、方案节里没有这一块**：报错，不是静默跳过——落成的人要知道账记在哪。
- **「还没落成」被写进「成品」那一格**：报错并说清这四个字是这一块里的一句话；`check_landing.py` 单跑时也要认得出这一种（不能当成一个读不到的路径去报「读不到」）。
- **命令行上给了成品路径、文档那边却是坏的**：照旧不看文档、照旧能跑，`partial`（分批降级）仍按文档里有没有那句话算。
- **用例那份里还留着这一块**：报提示不报错，老产出不会因为没搬而红。

```python
def impl_place_block(body):
    """切出第七份某个方案节里的「成品落点」那一块；没有这一块时返回 None。

    与 place_block 分开写：那一个切到下一个 `^##` 为止，用在用例那份上是对的
    （它是顶层小节，与别的块并列）；第七份里这一块是方案节底下的 `###`，切到
    下一个 `##` 会把后面几个方案节一起吞进来。这里切到下一个 `^#{1,3}` 为止。
    """
    m = re.search(r"^#{3,}\s*[^\n]*" + PLACE_HEAD + r"[^\n]*$", body, re.M)
    if not m:
        return None
    rest = body[m.end():]
    nxt = re.search(r"^#{1,3}\s", rest, re.M)
    return rest[:nxt.start()] if nxt else rest
```

```python
def check_place(body, rep, where):
    """第七份某个方案节里的「成品落点」那一块：在不在、表齐不齐。

    只管机械项——成品路径读不读得到、编号在成品里出没出现，归 check_landing.py。
    这一块落成之后才填得全，所以写成「还没落成」也算填了；分几批落成时两种写法并存
    （模板第十节）：列出来的那些行照旧逐行查，那句话交代剩下还没落的几处。
    """
    block = impl_place_block(body)
    if block is None:
        rep.err(IMPL_DOC, "%s 里没有「%s」这一块——这一批落了哪几号、成品落在哪个"
                          "路径，写在这一块里" % (where, PLACE_HEAD))
        return
    # 那四个字得是这一块里的一句话，不能占「成品」那一栏：占了一栏，落成对照就把
    # 那一格当成一个成品路径去读，读不到退 2、只打一句「成品一份都没读到」——那句
    # 话指不到这儿来。只认「成品」栏，与 check_landing 的 place_paths 认的是同一格。
    for head, rows in tables(block):
        if not all(c in head for c in PLACE_COLS):
            continue
        i = head.index(PLACE_COLS[0])
        bad = [row[i] for row in rows if len(row) > i and NOT_YET in row[i]]
        if bad:
            rep.err(IMPL_DOC, "%s 的「%s」表「%s」栏里写着「%s」——这四个字是那一块里"
                              "的一句话，不占表里的一格；这一栏写的是成品路径"
                    % (where, PLACE_HEAD, PLACE_COLS[0], NOT_YET))
            return
    head, rows = pick(tables(block), PLACE_COLS)
    if head is None:
        if NOT_YET in block:
            rep.ok("%s 的「%s」写着「%s」——落成之后回来把表填上，再跑一遍落成对照"
                   % (where, PLACE_HEAD, NOT_YET))
            return
        rep.err(IMPL_DOC, "%s 的「%s」里没有那张表（表头应为：%s）；成品还没落成的话，"
                          "那一块写「%s」"
                % (where, PLACE_HEAD, " | ".join(PLACE_COLS), NOT_YET))
        return
    if not rows:
        if NOT_YET in block:
            rep.ok("%s 的「%s」写着「%s」，一条都还没落成——落成之后回来把表填上，"
                   "再跑一遍落成对照" % (where, PLACE_HEAD, NOT_YET))
            return
        rep.err(IMPL_DOC, "%s 的「%s」表一行都没有——一份成品也要有一行；还没落成就写"
                          "「%s」" % (where, PLACE_HEAD, NOT_YET))
        return
    broken = 0
    for row in rows:
        if len(row) < len(PLACE_COLS) or not all(row[:len(PLACE_COLS)]):
            rep.err(IMPL_DOC, "%s 的「%s」表有一行有空栏：%s"
                    % (where, PLACE_HEAD, " | ".join(row)))
            broken += 1
    if not broken:
        if NOT_YET in block:
            rep.ok("%s 的成品落点表 %d 行；这一块里还写着「%s」——剩下那几处落成之后"
                   "回来补上" % (where, len(rows), NOT_YET))
        else:
            rep.ok("%s 的成品落点表 %d 行" % (where, len(rows)))
```

def check_sections(texts, rep):
    """模板说测试用例规格说明分四块写。多出来的顶层小节只提示不判错——
    多一段算不算「多造」是人的判断，脚本不替人定。

    「成品落点」已经搬到第七份的方案节里，所以它不在 known 里：老产出里还留着的，
    单报一条提示指到新住址，别混进那句泛泛的「多出来的算不算多造，自己定」。
    """
    heads = re.findall(r"^##\s+(.+)$", texts.get(CASE_DOC, ""), re.M)
    known = ("覆盖项", "测试用例", "对应表", COVER_HEAD)
    extra = [h for h in heads if not any(k in h for k in known) and PLACE_HEAD not in h]
    if extra:
        rep.warn(CASE_DOC, "有模板四块之外的顶层小节：%s"
                           "（模板说这份分四块写；多出来的算不算多造，自己定）" % "、".join(extra))
    if [h for h in heads if PLACE_HEAD in h]:
        rep.warn(CASE_DOC, "「%s」这一块已经搬到第七份 %s 的方案节里（这一份不再有它）——"
                           "搬过去之后这一节可以删掉" % (PLACE_HEAD, IMPL_DOC))

```python
def place_paths(texts, impl):
    """从第七份各方案节的「成品落点」表里取成品路径。

    返回 (路径列表, 说明, 是不是「还没落成」, 是不是落了一部分)。第七份不在、
    一节都没有、或者每一节都只写着「还没落成」时，路径列表为空，说明写清是哪一种。
    第三个元素单独回一个标志，因为「还没落成」与另外几种「没拿到路径」不是一回事：
    它的退出码不一样（3 对 2，见 main）。

    第四个元素管的是分几批落成（模板第十节）：已经落成的列成表、那句话交代还没落的
    那几处，这时路径拿得到、账也该查，只是「定义了却没在成品里出现」那一条要降成
    提示。多方案节时按全部节合并：只要有一节还写着那句话，就按分批算。

    表里的路径按当前目录解——与命令行给路径时一样。
    """
    if not impl:
        return [], "产出目录里没有 %s，也没在命令行上给成品路径" % check_docs.IMPL_DOC, True, False
    schemes = check_docs.impl_scheme_sections(impl)
    if not schemes:
        return [], "%s 里没有一个「%s」节" % (check_docs.IMPL_DOC,
                                              check_docs.IMPL_SCHEME_MARK), True, False

    paths, not_yet, seen = [], False, False
    for _head, body in schemes:
        block = check_docs.impl_place_block(body)
        if block is None:
            continue
        seen = True
        if NOT_YET in block:
            not_yet = True
        for head, rows in check_docs.tables(block):
            if not all(c in head for c in PLACE_COLS):
                continue
            i = head.index(PLACE_COLS[0])
            for row in rows:
                if len(row) > i and row[i]:
                    cell = row[i].strip("`").strip()
                    # 「还没落成」被写进「成品」栏了：它是那一块里的一句话，不占格子
                    # （模板第十节）。当成路径去读只会得到一句「成品一份都没读到」，
                    # 那句话指不到病根；这儿认出来，照「还没落成」那一种报。
                    # check_docs 也拦这一种，但这份脚本单跑时也得说得出话。
                    if NOT_YET in cell:
                        return [], "成品落点表上写着「%s」" % NOT_YET, True, False
                    paths.append(cell)
    if paths:
        return paths, "", False, not_yet
    if not_yet:
        return [], "成品落点表上写着「%s」" % NOT_YET, True, False
    if not seen:
        return [], "%s 的方案节里没有「%s」这一块，也没在命令行上给成品路径" \
                   % (check_docs.IMPL_DOC, check_docs.PLACE_HEAD), False, False
    return [], "「%s」那一块里没有成品落点表" % check_docs.PLACE_HEAD, False, False
```
