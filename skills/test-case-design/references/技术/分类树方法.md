# 分类树方法

## 一、测试模型

分类树方法的测试模型是分类树，由分类和类别两层构成。根是被测项，下一层是分类，分类下是类别。这个模型可以用图形表示，也可以用纯文本表示。

分类树方法应使用一种测试模型，该模型根据“分类”将测试项的输入域进行划分，并且用分类树的方式进行图形化表示。每个分类都由一组完整的、独立（不重叠）的“类”（分类可取的值）组成。根据测试的严格程度，这些类可以进一步分类（甚至递归地）为子分类和子类。

注：分类树方法的分区过程与等价类划分类似。主要区别在于，在分类树方法中，划分（分类和类别）需完全不相交，而在等价类划分法中，根据技术应用的不同，等价类可能会重叠。

## 二、测试覆盖项

分类树方法的测试覆盖项是类别的组合。

为分类树识别测试覆盖项有两种方法：

——当要求“最小化”测试覆盖率时，测试覆盖项应覆盖分类树中叶节点所代表的类。

——当要求“最大化”测试覆盖率时，测试覆盖项应覆盖分类树中叶节点所代表类的唯一组合。

取哪一档由测试完成准则与风险级别决定。

## 三、导出测试用例

导出测试用例应遵循以下步骤：

应导出测试用例以执行这些测试覆盖项。在导出测试用例时，每个测试用例中都应包括类的组合。

注：类的组合通常用组合表来表示。

a）根据所选的覆盖标准，测试用例尚未覆盖的类组合，将其纳入当前测试用例。

b）确定当前测试用例中每个类别中尚未赋值的输入值。

c）将输入应用于测试依据，确定测试用例的预期结果。

d）重复步骤 a) 至 c)，直到达到要求的测试覆盖率级别。

## 四、覆盖率

覆盖率按 C＝N÷T 计算，三个量在这门技术里各指什么如下：

对于最小化组合覆盖率，应按以下定义计算：

——C 分类树_最小化是最小组合分类树方法的覆盖率；

——N 是执行的测试用例所覆盖的类数量；

——T 是类的总数量。

对于最大化组合覆盖率，应按以下定义计算：

——C 分类树_最大化是最大组合分类树方法的覆盖率；

——N 是执行测试用例覆盖的唯一组合类的数量；

——T 是类的唯一组合的总数量。

覆盖率要求有档位，分为以下几档：

——最小化：每个类需至少在一个测试用例中包含。

——最大化：需对所有类别组合进行测试。

## 五、算例

下面的算例完整走一遍从测试依据到覆盖率的过程。

### 测试依据

考虑测试项 travel_preference 的测试依据，该测试项记录了某组织员工的旅行选项，他们因为工作的需要到国内主要城市出差。旅行偏好的每个集合通过一些单选按钮来选择，这些单选按钮由下面的输入选项组成：

目的地 = 北京、上海、广州、深圳、武汉、西安、成都、重庆

舱位 = 头等舱、公务舱、经济舱

座位 = 靠过道、靠窗

膳食偏好 = 糖尿病餐、无麸质、全乳素食、低脂肪/胆固醇、低乳糖、严格素食、标准

每个分类中选择一个类的任意组合都会显示“成功预订”信息，而任何其他输入都会显示“无效输入”的错误信息。工作人员不能选择不用餐，因此示例中不支持该选项。

### 覆盖率

最小化档：已识别的类总数量 T＝20；8 条测试用例覆盖到的类数量 N＝20；覆盖率 C 分类树_最小化＝N÷T＝20÷20＝100%。
