# 等价类划分

## 一、测试模型

等价类划分的测试模型是等价类，分有效等价类与无效等价类两种。这个模型可以用图形表示，也可以用纯文本表示。

等价类划分以覆盖等价类为基础。这些等价类的导出基于这样一种预期：同一等价类内的取值应由测试项以相似的方式处理。

应创建测试模型，以识别测试项的等价类。一个合适的测试模型可展示测试项预期执行的各种功能，并从中导出等价类。这些功能可视为一组过程，可分解为输入过程、内部过程和输出过程。

测试项规格说明中描述的功能，通常可用于识别其内部过程。分析测试项的输入和输出，有助于确定其可能的输入和输出过程。

宜为测试项的有效和无效功能（对应有效和无效输出）以及有效和无效输入分别识别等价类。在此周境下，无效功能指的是规格说明中未定义、且在测试项正确实现中没有合理预期的功能；类似地，无效输入是指那些被测试项忽略或导致测试项输出错误信息的输入。

测试项的等价类可能会重叠，在某些情况下，一个等价类可能是另一个等价类的子集。通过增加测试模型的细节，往往可以导出更多的等价类，通常是现有等价类的子集。随着更多细节和等价类的增加，完全覆盖测试模型所需的测试用例数量可能会增加。

示例：对于期望将小写字母字符作为（有效）输入的测试项，可根据测试过程中所需的严格程度，推导出包含整数、实数、大写字母字符、符号和控制字符的无效输入等价类。如果模型中将这些无效输入分别划分为独立等价类，则需分别测试才能实现全覆盖；若将所有无效输入合并为一个等价类，则仅需一次测试即可实现全覆盖。

注1：未被规格说明定义输入、功能或输出（常见情况）相对应的无效等价类通常基于测试人员的经验与主观判断，因此不同测试人员经常会得出不同的无效等价类。在应用基于经验的技术（如错误猜测）时，也会出现这种主观形式的测试设计。

注2：域分析通常归类为等价类划分和边界值分析的结合。

## 二、测试覆盖项

等价类划分的测试覆盖项是等价类，每个等价类都识别为一个测试覆盖项。

每个等价类都应识别为一个测试覆盖项。等价类划分没有覆盖档位可选，要求全面覆盖所有等价类。

## 三、导出测试用例

导出测试用例应遵循以下步骤：

应导出测试用例，以执行测试覆盖项（即等价类划分）。

a）确定选择测试覆盖项组合的方法，以通过测试用例进行覆盖。两种常见的方法如下：

1）一对一方式，即导出每个测试用例仅覆盖一个特定的等价类；

2）最小化方式，用导出最少数量的测试用例，使每个等价类至少被覆盖一次。

注：选择测试覆盖项组合的其他方法，见[组合测试](组合测试.md)。

b）根据步骤a)中选择的方法，选择纳入当前测试用例的测试覆盖项。

c）识别用于执行测试用例所覆盖测试覆盖项的输入值，并为该测试用例所需的其他输入变量选取任意有效值。

d）将输入应用于测试依据，确定测试用例的预期结果。

重复步骤 b) 至 d)，直到达到所要求的测试覆盖率级别。

选值纪律：一对一测试用例对于测试错误条件（即试图强制输出特定错误信息时）特别有用，可以减少某一错误条件停止处理和/或遮蔽或阻断其他错误条件发生的可能性，缺点是需要更多的测试用例；最小化方式的缺点是在测试失败的情况下，由于同时运行了多个新等价类，可能很难定位根本原因。因此，一种常见的方法是将这两种方法结合起来，采用最小化等价类划分设计有效的测试用例，采用一对一等价类划分设计无效的测试用例。

## 四、覆盖率

覆盖率按 C＝N÷T 计算，三个量在这门技术里各指什么如下：

——C 等价类是等价类的覆盖率；

——N 是已执行测试用例所覆盖的等价类数量；

——T 是已识别的等价类总数量。

要求全面覆盖所有等价类。

## 五、算例

下面的算例完整走一遍从测试依据到覆盖率的过程。

### 测试依据

以 generate_grading 的测试项为例，测试依据如下：

该组件接收考试成绩（不高于 75 分）和课程作业（c/w）成绩（不高于 25 分）作为输入，通过计算总成绩（考试成绩与作业成绩之和）来得到等级，规则如下：

| 总成绩 | 等级 |
|:---|:---|
| 大于或等于 70 | “A” |
| 大于或等于 50，但小于 70 | “B” |
| 大于或等于 30，但小于 50 | “C” |
| 小于 30 | “D” |

在检测到无效输入（例如，成绩超出了预期的范围）时，组件将输出一条错误信息（“FM”）。所有的输入都以整数形式传递。

### 测试模型（TM-1）

模型把识别出的等价类按处理环节分组列出：

| 处理环节 | 等价类 |
|:---|:---|
| 输入处理：考试成绩（e）的有效等价类 | 0 ≤ e ≤ 75 |
| 输入处理：考试成绩（e）的无效等价类 | e < 0；e > 75；e = 实数；e = 字母；e = 特殊字符（如 @、#、{、null） |
| 输入处理：课程作业成绩（c）的有效等价类 | 0 ≤ c ≤ 25 |
| 输入处理：课程作业成绩（c）的无效等价类 | c < 0；c > 25；c = 实数；c = 字母；c = 特殊字符（如 @、#、{、null） |
| 内部处理：总成绩（t）的等级条件 | 70 ≤ t ≤ 100（等级“A”）；50 ≤ t < 70（“B”）；30 ≤ t < 50（“C”）；0 ≤ t < 30（“D”） |
| 内部处理：错误信息 | 输出 = “E”；触发错误信息“FM” |
| 输出处理 | 产生输出（A、B、C、D 或 FM）；未产生输出 |

### 测试覆盖项

测试覆盖项是测试模型中显示的等价类，共 20 个：

源自输入处理：

- TCOV-1：0 ≤ 考试成绩 ≤ 75
- TCOV-2：0 ≤ 课程作业成绩 ≤ 25
- TCOV-3：考试成绩 < 0
- TCOV-4：考试成绩 > 75
- TCOV-5：课程作业成绩 < 0
- TCOV-6：课程作业成绩 > 25
- TCOV-7：考试成绩 = 实数
- TCOV-8：考试成绩 = 字母
- TCOV-9：考试成绩 = 特殊字符（如 @、#、{、null）
- TCOV-10：课程作业成绩 = 实数
- TCOV-11：课程作业成绩 = 字母
- TCOV-12：课程作业成绩 = 特殊字符（如 @、#、{、null）

源自内部处理：

- TCOV-13：“A”的条件 70 ≤ 总成绩 ≤ 100
- TCOV-14：“B”的条件 50 ≤ 总成绩 < 70
- TCOV-15：“C”的条件 30 ≤ 总成绩 < 50
- TCOV-16：“D”的条件 0 ≤ 总成绩 < 30
- TCOV-17：输出 = “E”
- TCOV-18：触发错误信息“FM”

注：假定 E 级的产生是由于程序中错误地包含了无关的非必要功能。

源自输出处理：

- TCOV-19：产生输出（A、B、C、D 或 FM）
- TCOV-20：未产生输出

### 测试用例

共识别出 20 个测试覆盖项，从而导出了 20 条测试用例，每条用例只覆盖一个特定的等价类（一对一方式）。所有测试用例的前置条件均相同：该应用已准备好接收输入考试成绩和课程作业成绩的输入。

表中 e 是考试成绩，c 是课程作业成绩，t 是总成绩；“-”表示这一栏在这一条用例里没有值。

| 用例编号 | 输入（考试成绩） | 输入（课程作业成绩） | 总成绩（计算） | 测试覆盖项 | 被测等价类 | 预期结果 |
|:---|:---|:---|:---|:---|:---|:---|
| TC-1 | 60 | 15 | 75 | TCOV-1 | 0 ≤ e ≤ 75 | “A” |
| TC-2 | -10 | 15 | - | TCOV-3 | e < 0 | “FM” |
| TC-3 | 93 | 15 | - | TCOV-4 | e > 75 | “FM” |
| TC-4 | 40 | 20 | 60 | TCOV-2 | 0 ≤ c ≤ 25 | “B” |
| TC-5 | 40 | -15 | - | TCOV-5 | c < 0 | “FM” |
| TC-6 | 40 | 47 | - | TCOV-6 | c > 25 | “FM” |
| TC-7 | 60.5 | 15 | - | TCOV-7 | e = 实数 | “FM” |
| TC-8 | Q | 15 | - | TCOV-8 | e = 字母 | “FM” |
| TC-9 | $ | 15 | - | TCOV-9 | e = 特殊字符 | “FM” |
| TC-10 | 40 | 20.23 | - | TCOV-10 | c = 实数 | “FM” |
| TC-11 | 40 | G | - | TCOV-11 | c = 字母 | “FM” |
| TC-12 | 40 | @ | - | TCOV-12 | c = 特殊字符 | “FM” |
| TC-13 | 60 | 20 | 80 | TCOV-13 | 70 ≤ t ≤ 100 | “A” |
| TC-14 | 44 | 22 | 66 | TCOV-14 | 50 ≤ t < 70 | “B” |
| TC-15 | 32 | 13 | 45 | TCOV-15 | 30 ≤ t < 50 | “C” |
| TC-16 | 12 | 5 | 17 | TCOV-16 | 0 ≤ t < 30 | “D” |
| TC-17 | 5 | 5 | 10 | TCOV-17 | E | “D” |
| TC-18 | 80 | 60 | - | TCOV-18 | FM 条件 | “FM” |
| TC-19 | 47, 3 | @@@@ | - | TCOV-19 | 生成输出 | “FM” |
| TC-20 | 空 | 空 | - | TCOV-20 | 无输出 | “FM” |

注：表中 TC-17、TC-20 两行的「预期结果」与「被测等价类」对不上。预期结果由测试依据推出，遇到这种出入时以测试依据为准。

根据不同的实现方式，可能无法执行包含无效输入值的测试用例（如 TC-2、TC-3、TC-5 至 TC-12 以及 TC-18 至 TC-20）。例如，在某些编程语言中，如果输入变量被声明为正整数，则可能无法给它赋值。尽管如此，为了确保完整性，仍值得考虑所有测试用例。

同一批等价类也可以用最小化方式导出：测试覆盖项有两个输入和一个输出，每个测试用例可能“覆盖”三个等价类，两个输入等价类和一个输出等价类，因此 11 条测试用例即可覆盖全部 20 个测试覆盖项。本例采用一对一方式，因为它可更直观地展现等价类与测试用例之间的对应关系。

### 覆盖率

已识别的等价类总数量 T＝20；20 条测试用例覆盖到的等价类数量 N＝20；覆盖率 C 等价类＝N÷T＝20÷20＝100%。
