# 测试环境需求

测试项：`skills/token-counter/scripts/count_tokens.py`（DeepSeek token 精确计数脚本）。

| 唯一标识符 | 测试环境项 | 描述 |
|:---|:---|:---|
| ENV-1 | 操作系统与解释器 | Windows x64 + CPython 3.13.7（本次实测所用）。脚本自身要求 CPython ≥ 3.9；打包的引擎 wheel 是 abi3、面向 Windows x64，换到别的系统或别的位置数就装不上，会走联网安装那条路 |
| ENV-2 | 计数引擎 | `tokenizers` 0.22.2。版本要与打包 wheel 的版本号一致——脚本是按「装没装引擎」判断的，装了别的版本它也不会去换 |
| ENV-3 | 控制台与进程参数编码 | 本机控制台默认代码页为 GBK（cp936）。命令行参数必须以参数列表的形式直接传给新起的进程（例如用 `subprocess` 传列表，不经 shell）；把 emoji、U+FF5C、U+2581 这类字符当命令行文本手敲进 GBK 控制台会被改坏，测出来的数是错的。测试时用来跑用例的那个程序自身，写文件要指明 UTF-8，喂标准输入要喂字节流而不是文本流 |
| ENV-4 | 干净虚拟环境 | 一个没装 `tokenizers` 的 Python 虚拟环境，供 TC-22 至 TC-24 使用。判断「没装」用 `importlib.util.find_spec` 查，不要只看 `pip list`。每跑完一条用例就要重建或换新环境 |
| ENV-5 | 网络状态 | 三份可切换的状态：全程断网（TC-22、TC-24 用）；能访问 PyPI（TC-23 用）；能访问 DeepSeek API（TC-25 用）。三份状态都要能确实摆出来，摆不出来时 TC-22 至 TC-25 只能记为未执行 |
| ENV-6 | API 凭据 | 一个可调用 DeepSeek 对话补全接口的密钥，供 TC-25 使用。凭据不要写进任何产出文档或提交进仓库 |
| ENV-7 | 文件系统 | 执行期间要能在临时目录里新建文件（含只写字节的二进制文件）、新建一个目录备用，并能在执行后删除它们 |
| ENV-8 | 输出换行的比对口径 | Windows 上 Python 的文本模式会把 `\n` 输出成 `\r\n`。比对标准输出时按行比对，忽略行尾是 `\n` 还是 `\r\n`；这一条不影响 `chars` 的数值 |
| ENV-9 | 测试项的文件布局 | `skills/token-counter/` 下要有 `tokenizer.json`，以及 `scripts/count_tokens.py` 与 `wheels/` 两个子项。脚本按自身所在位置向上一级取词表，测试期间不得改动这三者的相对位置，否则测到的是别的失效原因，不是计数本身 |
