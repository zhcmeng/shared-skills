# weread-book-export

把微信读书里的一整本书导成 Markdown：一章一个文件，另出一份带目录的 `README.md`，插图存到本地。

这份 README 是给人看的：Claude 跑这个技能时不读它，读的是 [SKILL.md](./SKILL.md)。

## 它怎么拿到正文

微信读书的阅读器把正文画在 `canvas` 上，网页的 DOM 里一个字都没有——所以「复制页面文本」「抓 innerHTML」这类办法在这里全都不管用。

这个技能换了条路：往浏览器的 `CanvasRenderingContext2D.prototype.fillText` 上挂一个钩子，每次绘字都把「字、x、y、字体」记下来。同一基线的字 y 相同、从左往右 x 递增，按 y 归行、行内按 x 排序拼起来，就是屏幕上那一行，**一个字不差**，也没有 OCR 的识别错误。

章节边界、目录、插图位置都是从页面上读的；翻页、切模式、点目录都用真实鼠标点击，节奏带随机停顿，不做定时器式的连续请求。

## 装法

跟着 `shared-skills` 插件装好后自动注册，不用单独安装。

只想在这个目录里单独用，把这个目录拷到 `~/.agents/skills/weread-book-export/` 或某个工程的 `.claude/skills/` 下。

跑之前机器上要有 [uv](https://docs.astral.sh/uv/)——脚本靠 `uv run --with playwright` 现装依赖，不用你自己建虚拟环境。

## 第一次跑

**会弹出一个浏览器窗口要你扫码登录微信读书。** 登录态存在：

```
%LOCALAPPDATA%\weread-book-export\browser-profile
```

同一个目录只留一份，之后跑不用再扫。要换账号、或者登录态坏了，删掉这个目录重跑即可。

脚本默认用 Edge。要换 `--browser-channel chrome`。

## 产物

```
<输出目录>/
├── README.md                  # 书名、作者、来源、导出日期、目录
├── 01-版权信息.md
├── 02-推荐序-我们向江南春学什么.md
├── ...
└── images/
    ├── 05-001.jpg             # 第 5 章第 1 张图
    └── 05-002.jpg
```

- 章名里的 `\ / : * ? " < > |` 换成 `-`，超过 40 字截断，序号按目录顺序补零
- 每章开头是 `# 章名`，小节标题按字号大小映射成 `##`、`###`
- `README.md` 每写完一章就重写一次，中途断了目录也是全的

## 中断与重来

每导完一章就记一次进度，存在 `%LOCALAPPDATA%\weread-book-export\state\<输出目录名>.json`。

- **接着跑**：重跑同一条命令，从没导完的那一章继续
- **从头再来**：加 `--fresh`，或者直接把那个状态文件删掉
- 状态文件在，但你想导到另一个目录：换个 `--out` 就等于开了一份新进度

## 要注意的

- **需要会员**。碰到付费墙会停下报告停在哪一章，不会把半章写进文件。
- **不导笔记和划线**，导的是正文全文。
- **不还原排版**：字号、颜色、分栏都不管，只保留段落与标题层级
- 导出来的内容**只供自己学习用**，别再分发
- 平台要求验证、限流时脚本会停下，不会换 IP、不会反复重试

## 脚本分工

`scripts/` 下六个文件，各管一段：

| 文件 | 管什么 |
|:---|:---|
| `weread_export.py` | 命令行入口，把下面这些串成一趟导出 |
| `weread.py` | 页面上的动作：登录判定、搜书、目录、切滚动模式、挂钩子、截字形、翻章、取图 |
| `layout.py` | 字形还原成行、剔噪声、拼段落、切掉翻章时重画的上一屏 |
| `catalog.py` | 目录扁平化成章节列表、生成合法的文件名 |
| `markdown.py` | 渲染章节页与目录页 |
| `state.py` | 断点续跑的状态读写 |
| `browser.py` | 启动浏览器、像人的点击与滚动、随机停顿 |

只有 `layout.py`、`catalog.py`、`markdown.py`、`state.py` 有单元测试——它们是不碰浏览器的纯逻辑。浏览器那几层靠实跑验证：每个行为都要连真站点才有意义，拿假对象测等于在测自己写的假对象。

测试在仓库根的 `tests/weread-book-export/` 下：

```bash
bash tests/run.sh weread-book-export
```
