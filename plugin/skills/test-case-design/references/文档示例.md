# 文档示例

本文把五份产出文档的填写示例收在一起，让读者看到填好的文档长什么样。每份文档都收了两个项目的示例；有收不全的，在那一节写明为什么。

示例里的编号取自原例，照抄未改——`[模型编号：23]`、`T1`～`T6`、`Lid-1`、`Lid-2`、`TP-3`、`DBR-1`～`DBR-10`、`UV/TRT-14 33a`、`E-1`～`E-5` 都是原例自带的；实际使用时按本技能的编号方案编，即 `TM-`、`TCOV-`、`TC-`、`TP-`、`DATA-`、`ENV-`，见[文档模板](文档模板.md)第二节。

五节里列的不是同一套文档。「传统企业 B」的五个示例各是独立项目：测试模型规格说明和测试用例规格说明讲的是盖板操作，测试规程规格说明是 NCS 样品分析仪，测试数据需求是 UV/TRT-14 33a 的 PC 部分，测试环境需求是笔记本电脑与测试管理工具。不要把五节当成一套连续文档读。

文中凡以「注：」起头的行，都是本文加的说明，不是文档内容。

## 一、测试模型规格说明

### 敏捷企业 A

敏捷企业 A 开发的新订阅系统项目中，团队已创建了一个高层测试模型，用以展示用户可选择的不同订阅选项及相关操作。持续维护该模型（在每次迭代中保持更新），能够支持团队为待实现的新功能生成测试用例，同时也支持回归测试。该测试模型规格说明可在产品门户上获取，最新版本发布在开发室故事板测试计划板块右上角。

### 传统企业 B

**唯一标识符**：[模型编号：23] 盖板操作模型

**目标**：产品的一种衍生型号需配有防护盖板，保护开展检测工作的技术人员。

**优先级**：1

**测试策略摘要**：状态转移测试

注：原例这一栏只写了技术名；按[文档模板](文档模板.md)第三节的「测试策略摘要」栏，这一栏要写全哪几门技术、怎么组合、完成准则是什么。

**测试模型**：转盘运转时，盖板需将其完全覆盖。启动转盘前，需先将盖板锁定；转盘未完全停止前，无法打开盖板。设备配备两组传感器，分别用于检测盖板是否锁定以及转盘是否运转。

只要盖板处于锁定状态，即可启动转盘向前或向后移动。若要改变转盘方向，需先停止转盘运转，但无需打开盖板。

操纵面板上有以下按键：

——锁

——打开

——前进

——后退

——停止

盖板操作测试模型可以用 [模型编号：23] 盖板操作模型状态迁移图来表示，其中状态和转换都有编号，事件“P”表示“按下”。
