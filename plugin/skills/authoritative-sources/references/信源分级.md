# 信源分级

在研究与分析中，信源的准确性取决于三件事：信息是怎么产生的、发布者有没有法律责任、专业机构有没有做过深度加工。按这三点分为三级，另有一类禁止作为信源。

## 判定顺序

按序套用，命中即定级：

1. 承载链接是否属于 GitHub 及其衍生页面（github.com、raw、Pages、Gist、Issue、Release）？→ **禁止作为信源**。这一条先于内容判据生效。
2. 是否具有法律披露义务或官方背景（年报、定期报告、交易所与监管公告、官方统计、公司官网公告）？→ **一级**。
3. 是否由专业机构或专家深度加工（券商研报、深度报道、专家访谈纪要）？→ **二级**。
4. 是否属于网络碎片、个人见解或自媒体（百科、百家号、网易号、社区评论）？→ **三级**。

全部未命中或边界存疑时，按下面的完整定义逐级比对；仍无法确定就如实说明无法定级，不硬套。

## 一级：官方与核心证据源

- **定义**：具有法律披露义务、由官方机构发布、或直接源自交易与业务系统的原始数据。
- **特征**：最高权威性，可作为定论证据，发布者承担法律责任。
- **典型来源**：交易所公告、招股说明书、年报季报、问询函回复、审计报告；国家统计局、海关总署、央行与各部委发布的统计公报；公司官网的新闻稿、产品白皮书、投资者关系页面。
- **使用场景**：验证核心假设、计算指标、确认竞争格局、作为直接引用证据。

## 二级：专业与机制研究源

- **定义**：由专业研究机构、资深媒体或行业专家基于一级信息做的二次加工、深度分析或逻辑梳理。
- **特征**：中等权威性，适合理解逻辑与机制，需警惕分析师的主观偏见。
- **典型来源**：券商研报、行业深度报告；财新、彭博、路透等专业媒体的深度报道；专家网络访谈纪要；行业协会与专业数据机构的报告。
- **使用场景**：理解行业运行机制、获取难以直接查到的调研数据、交叉验证核心假设。

## 三级：碎片与线索源

- **定义**：分散在网络社区、社交平台或非专业媒体上的碎片化观点、传闻或个人见解。
- **特征**：最低权威性，仅用于发现线索，严禁直接作为证据。
- **典型来源**：百科与聚合平台、百家号、搜狐号、网易号等自媒体；雪球、股吧、知乎、微博、非官方认证的微信公众号；碎片化快讯、论坛讨论、非正式流传的个人笔记。
- **使用场景**：寻找研究课题、观察市场情绪、捕捉小众信号、在无官方数据时作为推测起点（需标注风险）。

## 易误判来源

- **百度百科、维基百科**：人人可编辑的聚合信息，一律按三级处理。
- **微信公众号**：除官方机构认证账号外，一律按三级处理；认证账号按发布主体与内容套用判定顺序，官方发布可按一级。

## GitHub 黑名单

GitHub 及其衍生页面一律不得作为信源：不进事实判断、关键数字、行业结论与引用。

原因：平台的角色是托管与协作，不是事实披露与责任发布；页面内容可能是转载、镜像或个人整理，无法证明它是原始发布渠道；链接稳定性与版本边界也不满足正式证据要求。

唯一允许的用途是作**线索入口**——顺着它回溯原始来源（官网、媒体原文、论文页面、监管披露、机构页面），或定位作者与版本信息。无法回溯时，该信息不进正文证据链，只能作为待证线索。

## 三级信源引用约束

判定为三级、仍然需要引用时（只作辅助，不作关键证据）：

1. 不得作为孤证：关键数据与核心结论不能只靠三级信源。
2. 引用处必须标注局限性，格式：
   `> **存疑表述**：[说明局限，如「该信息源自自媒体，未经官方审计核实，仅作逻辑参考」]`
3. 看到三级信息时，同时向上溯源到一级或二级。

## 证据支撑判断

关键结论须有**至少 1 个一级**，或**至少 2 个互不相关的二级**信源支持，才算证据充分。不足时不得作为定论引用：指出缺哪一层，引导补强，或降级成推测表述。

## 交叉验证

高等级信源不等于绝对真理，年报也可能造假。判断重要结论时，用不同等级、不同立场的信源互相对照。可以从时效、相关、权威、准确、目的五个维度辅助审视。
