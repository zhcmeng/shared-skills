# 中国游戏行业

核实日期：2026-11-16

> 本文件是人工维护的来源清单，不是数据的副本。超过 6 个月未核实，引用前重新确认机构的发布频率与官网可用性。

## 这个行业的数据难点

官方只发审批明细，不发版号汇总数，数量要自己按公示表计数。市场收入与用户规模由行业协会发布，统计口径不公开——用户规模是否含小游戏、是否跨平台去重，都没有说明。买量成本只有机构白皮书与媒体转述，没有连续年度序列，且「买量总支出」与「单用户成本」经常被混为一谈。

## 口径陷阱

1. 游戏工委的市场实际销售收入是**国内**市场，不含海外，海外单列美元；2026 年起总额新增桌游。
2. 同为 2025 年手游市场：游戏工委 2570.76 亿元、艾瑞 2693.4 亿元、点点 2859.2 亿元。统计范围不同，不能混用，也不能互相验证。
3. Sensor Tower 只覆盖 App Store 与 Google Play，中国大陆仅 iOS，是预估不是财报收入。
4. QuestMobile 的手游 App 月活（6.72 亿）不等于游戏用户规模（6.83 亿）。
5. 国家新闻出版署只发审批明细，不发汇总数，版号数量要自己按公示表计数。

## 机构状态变化

- 伽马数据官网 joynews.cn 已 404 且证书异常，报告经微信公众号或镜像获取。
- data.ai 于 2024-03-18 被 Sensor Tower 收购，不再独立发布。

## 交叉验证建议

- 市场收入与用户规模用游戏工委的年度值；年度值与半年度值不要跨年混用。
- 手游市场规模不同机构口径不同，同一张图只用一家的序列，不拼接。
- 买量成本必须注明是总支出还是单用户成本；两者不能互相换算，除非同时拿到用户数。
