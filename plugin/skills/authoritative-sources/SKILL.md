# 权威数据源

## 什么时候用

- 开始检索行业数据、市场数据、行业规模、公司经营数据之前。
- 需要判断某个来源能不能当证据、能当到什么程度时。
- 需要判断已有证据够不够支撑一个结论时。

不用：具体的下载与入库（交给所在工程自己的流程）；引用格式校验；纯概念解释——「什么是 X」这类问题不需要检索。

本技能给的是判断与目录，不代替打开页面核实。

## 检索纪律

### 先本地、后外部

所在工程有本地素材库或检索工具时，先查本地已有什么。本技能管的是外部来源的选择，不替代本地检索。

### 哪些回答必须实际检索

| 类型 | 例子 |
|:---|:---|
| 事实性数据 | 市场规模、营收利润、市占率、价格、产能 |
| 行业判断 | 行业处于什么周期、产业链谁有定价权 |
| 公司信息 | 业务结构、商业模式、管理层动作 |
| 状态声明 | 某产品已被取代、某公司不再是龙头 |
| 对比判断 | A 和 B 的差别、为什么选 A 不选 B |

简单的概念定义可以基于已有知识；涉及具体数字、状态、行业格局时必须检索。检索结果与已有知识不一致时，以检索结果为准。

### 搜多少算够

| 档位 | 适用 | 底线 |
|:---|:---|:---|
| 单点事实 | 回答一个具体数字或事实 | 1 个权威一手源（一级或二级），标到「年份 + 章节或表号」或「页码 / 章节标题」 |
| 系统性整理 | 建文档、做行业概览、系统整理某主题 | 至少 4 轮不同角度检索；6 个独立来源；其中 3 个一级或二级；每个并列子主题各有专门信源；关键结论至少 2 个独立来源 |

关键结论只有单一来源时，标注「单一来源，待复核」。

### 什么主题找什么信源

| 主题 | 优先信源 | 不足时才用 |
|:---|:---|:---|
| 行业规模与格局 | 政府统计、监管机构公报、行业协会数据 | 券商行业研报、专业数据机构的行业报告 |
| 公司经营与财务 | 公司年报、官方公告、交易所披露 | 券商研报、专业数据机构 |
| 宏观与政策 | 央行、统计局、发改委等官方发布 | 专业机构研报 |
| 市场行情 | 交易所与官方数据 | 专业数据机构 |

媒体报道、自媒体、论坛只作辅助，不得作为关键结论的唯一依据。等级判定标准见 `references/信源分级.md`。

### 搜不到怎么办

1. 先穷尽路径：换关键词、换语言、换角度各试一遍，确认是真没有。
2. 如实标注缺口：写明缺什么、成因（数据不足、信源缺失、工具限制），以及已经试过的检索范围。
3. 可以降级：用次级信源时必须标明它的性质和局限，不假装是一手。
4. 禁止：用已有知识脑补成看似权威的结论；把单一来源写成公认事实。

### 自检

- 该搜的都搜了吗，还是用已有知识顶替了？
- 系统性整理时，角度、来源数、权威源数够了吗？
- 每个并列子主题都有专门信源吗？
- 关键数字能标到具体章节或页码吗？
- 搜不到的，都如实标注缺口了吗？

**未通过自检就继续检索，不得开始写作。**

### 反模式

- 只搜一两次就开写。
- 用一篇综述给所有子主题当唯一来源。
- 该找一级信源的主题只引媒体转述。
- 引用了数字却只给网站首页。
- 关键结论只有单一来源却不标注。

## 加新数据源

1. 在 `references/` 下按 `中国游戏行业.md` 的骨架写一个文件。
2. 在上一节的目录表里加一行。
3. 不修改其他文件。

骨架六节：核实日期、这个行业的数据难点、按用途查源、口径陷阱、机构状态变化、交叉验证建议。
