# 台账示例

一份真跑过的台账，删节之后抄在下面。首行照本技能的说法重写过，其余一字未动；删掉的是那一次活特有的部分：共享接口核对表、几段长裁定、后面几个任务的完整经过。留下的是一份台账站住需要的那几样。

行首的编号在这份里写成 `Task <N>`，是那次活自己的写法——换个技能，按那个技能怎么切活另起，正文第 4 步「每完成一件事」列了几种。

**这是示例，不是模板。** 它长成这样，是因为那次活长成这样：有 git 提交、有跑得动的检查脚本、分成了几个任务。换个技能，这些条件不一样，台账就该长成另一个样子。要看的是一份台账站住需要哪些东西凑齐，不是把这份的形状搬过去。
