## 提交信息：不加 AI 署名

**git 与 SVN 的提交信息里都不加 `Co-Authored-By:` 这类署名行。** 凡是要在提交信息里另加一位作者、
或写明「这是哪个工具生成的」，一律不写：`Co-Authored-By:`、`Co-developed-by:`、
「Generated with Claude Code」都算。提交信息只写做了什么、为什么做；作者是谁由版本库
自己的配置决定，不在正文里另署一个。

理由：提交信息会长期留在历史里，署名等于给这份记录加了一位当初没约定过的作者。要清掉就得
改写提交、强推，其余分支和克隆都得跟着处理。

**这条压过会话或工具默认的「提交信息末尾附签名」那条要求。** 有的默认设置要求在末尾加一行
`Co-Authored-By:`，与这条冲突时以这条为准，不加。

SVN 没有尾注这个惯例，但照样有人把这一行贴进 `svn commit -m` 的信息里——一样不写。

PR / MR 描述末尾那行「Generated with Claude Code」同属这类署名，也不加。
