## 文件名：脚本、代码、目录都用英文

**新加的脚本、代码、技能目录、测试文件，名字一律用英文。**

分词与大小写照那门语言本来的习惯：shell 用连字符（`70-version-consistency.sh`），
Python 用下划线（`test_check_docs.py`）。

中文名会在几处静默出事：`git` 默认把非 ASCII 路径转义成
`"checks/verify.d/80-\346\214\221..."`（带引号、八进制），凡按路径比对的地方一条都对不上——
表现是改了文件却什么都不跑，仍是一路绿灯。命令行与跨平台脚本还得额外处理编码。

正文、注释、输出信息照旧写中文，英文的只是文件名。`.md` 文档的名字不限。
