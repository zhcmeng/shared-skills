# 测试规程规格说明

测试项：`plugin/skills/translate-docs/` 整门技能。十条测试用例排成两条测试规程：一组考的是翻译规则那一侧（一份文档译出来像不像一比一），一组考的是工作流那一侧（给什么目标、做什么、报什么）。两条规程互不依赖，组内的用例之间也没有前置依赖，按各条自己的启动动作摆好就能跑。

## TP-1 内容侧的一比一：一份文档译出来

| 唯一标识符 | TP-1 |
|:---|:---|
| 英文名 | content_one_to_one |
| 目标 | 把翻译规则那一侧走一遍：三份不同形态的英文文档各自译出来，该译的都成中文、该留的一字未动、结构与原文逐项对应；依据没有规定的几处记下实际行为。 |
| 风险等级 | 高 |
| 执行器 | 子代理（要另起一轮执行：把技能整套交给被测那侧，发一条请求，取回复、执行过程与盘上的产出） |
| 改动文件 | 会写（跑起来被测那侧会往盘上写——写的是工作区里的样本副本旁边那份中文版；技能目录 `plugin/skills/translate-docs/` 本身一个字不动） |
| 启动 | 按 ENV-5 把 `plugin/skills/translate-docs/` 整套当作装好的技能交给被测那侧；按 ENV-4 在工作区里为每一条用例各备一份可写的样本副本（TC-1 用 DATA-1、TC-2 用 DATA-2、TC-3 用 DATA-3），各条请求里的路径指向各自那份副本；按 ENV-3 取会话记录（回复、执行的命令、派出的子代理）与每份文件跑前跑后的内容；两处运行环境按 ENV-1 与 ENV-2 都在本机。 |
| 有序执行测试用例 | TC-1 → TC-2 → TC-3。三条之间没有前置依赖，次序可以调换；高风险的两条排在前面。 |
| 与其他规程的关系 | 与 TP-2 互不依赖，先后都可以。 |
| 停止与结束 | 每条跑完，按该条数据项的重置需求把样本副本复位成原样；核对 `plugin/skills/translate-docs/` 跑完与跑前逐字节相同。 |

## TP-2 目标形态与产出：给什么、做什么

| 唯一标识符 | TP-2 |
|:---|:---|
| 英文名 | target_disposition |
| 目标 | 把工作流那一侧走一遍：单个文件、目录里还有待译的、目录里都译过了、没带目标、路径不存在、skill 名、要求覆盖重译、单文件已有中文版——八种情形各自走一遍，看落到哪条规则上、报了什么、盘上动了什么。 |
| 风险等级 | 高 |
| 执行器 | 子代理（要另起一轮执行：把技能整套交给被测那侧，发一条请求，取回复、执行过程与盘上的产出） |
| 改动文件 | 会写（跑起来被测那侧会往盘上写——写的是工作区里的样本副本旁边那几份中文版；技能目录 `plugin/skills/translate-docs/` 本身一个字不动） |
| 启动 | 按 ENV-5 把 `plugin/skills/translate-docs/` 整套当作装好的技能交给被测那侧；按 ENV-4 在工作区里为每一条用例各备一份可写的样本或目录副本（TC-4 与 TC-9 各用一份 DATA-5 的副本、TC-5 用 DATA-6、TC-10 用 DATA-4，TC-6 与 TC-7 不备样本），各条请求里的路径指向各自那份副本；TC-8 另需按 ENV-6 在场一个能被按名字定位到的技能；按 ENV-3 取会话记录与每份文件跑前跑后的内容；两处运行环境按 ENV-1 与 ENV-2 都在本机。 |
| 有序执行测试用例 | TC-4 → TC-5 → TC-6 → TC-7 → TC-8 → TC-9 → TC-10。七条之间没有前置依赖，次序可以调换；高风险的各条排在前面。 |
| 与其他规程的关系 | 与 TP-1 互不依赖，先后都可以。 |
| 停止与结束 | 每条跑完，按该条数据项的重置需求把样本副本复位成原样（TC-6 与 TC-7 没有样本，核对工作区里没有凭空多出文件）；核对 `plugin/skills/translate-docs/` 与 ENV-6 那个技能跑完与跑前逐字节相同。 |
