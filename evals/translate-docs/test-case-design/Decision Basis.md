# 决策依据

本文件记的是这份测试用例设计的过程。其余五份记结论——模型长什么样、覆盖项有哪些、用例怎么导的；这一份记每一处当时摆着哪几种做法、凭什么取了这一种。一条一行，按定下来的先后排。这份分两块写：先是「用户决策」（**可以直接改**），再是「模型决策」（**只增不改**——后面发现前面定错了，新加一条写明订正的是哪一条，原来那条留着）。

测试项是 `plugin/skills/translate-docs/` 整门技能。它没有脚本，一份文件就是全部——`SKILL.md` 既是技能正文，也是这次测试的依据。它给出两样对外契约：一是十条翻译规则（一比一规范，同时也是主代理校验产出的判据），二是四步工作流（定位目标、确定待译文件、并行派发子代理、校验并汇报）。判据因此分两层：一层看产出的 `-中文版.md` 长什么样，一层要读它跑起来一路做了什么（派没派子代理、报了成功还是失败）。
