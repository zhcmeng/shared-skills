# 开始写第一篇

这个站点的文章都是 Markdown，一篇一个文件，放在 `docs/` 下面。

## 文件怎么放

文件名用小写英文，词之间用连字符，比如 `getting-started.md`。同一主题的多篇文章放同一个子目录里，子目录名跟主题同名。

## 文章怎么写

开头写一个一级标题，就是这篇文章的题目。正文分节，每节一个二级标题。三级标题只在节里面还需要分层的时候用，别跳过二级直接用三级。

段落之间空一行。列表、代码块、引用块前后也各空一行。

## 链接怎么写

站内文章之间互相引用，用相对路径，从当前这篇的位置算起。比如同在 `docs/` 下的两篇，直接写文件名就行：

```markdown
见 [开始写第一篇](getting-started.md)。
```

链到子目录里的文章，把子目录名带上。链到站外，写完整的 `https://` 地址。

## 写完跑一遍

提交之前跑一次自查：

```bash
bash checks/verify.sh
```

它会顺着链接看指的路径在不在，也会看标题层级有没有跳级。红了就先修，再提交。
