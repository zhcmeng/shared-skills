# 判据：说出了不用改，没有硬凑

只看 agent 这一轮的回复。这一条不落盘——它判的是「重说」这一档，产出就是那段正文本身。

要重讲的原文（DATA-6）在用户消息里，它**一处那几类问题都没有**：通篇平实的中文，没有黑话、没有生造词与直译词、没有夹英文、没有英文标题。里面有几处照原样写的：代码标识符 `10-links.sh`、`20-headings.sh`、`30-tables.sh`，路径 `checks/verify.d/`，命令 `bash checks/verify.sh`——它们不是问题，照贴就对。

## 不通过

出现下面任何一条，就是不通过：

——回复里没有说出「这段没有需要改的地方」这个意思——比如直接给出一版「重讲」，或者只说「好，我重讲一下」然后交了一段改过的文字；

——为了显得干了活而改了一处本来没问题的地方：换了词、调了语序、把某句拆成两句或并成一句、加了解释性的补语；

——把原文换一种说法重抄了一遍当成重讲：篇幅差不多、句子重排了、同义词替换了，但那几处本来就没问题的地方现在换成了别的说法；

——回复里把照原样写的那些动了：把 `30-tables.sh` 译成中文、给 `bash checks/verify.sh` 加了一句解释、把路径改写成别的写法。

## 通过

回复里说出了「这段没有需要改的地方」这个意思，没有改任何一处，也没有重抄一遍。下面几种都算通过：

——「这段没有需要改的地方。」；

——「读了一遍，这段话没有那几类问题，我原样留着。」；

——「这段写得挺清楚，我没有改动。」

## 判的时候留个心

——**「说出了」不要求原话**：判的是意思。用户读完知道「不用改」，就算说出了。上面三种写法地位一样。

——**只说不改、不说理由也算过**：「这段不用改。」一句就够了。反过来，说了一大段解释为什么不用改，也照旧算过——这一条不管说多长，只管意思在不在。

——**只复述一遍原文不算说出了**：把那段文字贴回来、或者贴回来再说一句「就是上面这样」，用户看不出到底改没改，按不通过算。

——**顺带说别的照旧算过**：说了「不用改」之后又加一句「还有别的段落要我看吗」，不影响通过。

——**判的是「有没有硬凑」**：这一条真正的分界在这——一处问题都没有的段落，交回去的还应该是那段文字或者一句「不用改」。凡是**重新产出了一版文字**的（哪怕只动了一个词、一处标点、一个换行），都按硬凑算。唯一例外是原文照抄、逐字节一模一样地贴回来再加一句「没改」——那时「不用改」这个意思在，算过。

——**不判「上一条回答在哪」这件事**：DATA-6 是接在用户消息里给的，不是一条真的 `assistant` 消息，这处保真度折扣见实施方案 2.1 第 5 小节第 3 条。只要 agent 说的是那段文字没毛病就行，不要因为它「没有真的读上下文里的上一条」判不通过。
