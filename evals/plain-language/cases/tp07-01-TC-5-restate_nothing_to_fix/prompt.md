# 评测用例：上一条回答没毛病时不硬凑

## 这条用例防的是什么

跟 TC-4 是同一条规则的**反面**：`SKILL.md` 的重说那一档写着「原文没问题就说『这段没有需要改的地方』，不硬凑」。上一段文字一处问题都没有的时候，agent 有一种很自然的走偏——收到「我看不懂，重讲一遍」，就默认这段一定有问题，于是找出一两处「可以更顺一点」的地方改掉，或者干脆换一种说法把全文重抄一遍交回去。

两种做法都错：前者动了本来没问题的地方，后者看起来像交了活，其实一处问题都没解决，用户读完还是那样。

这一条钉三件事：回复里说出了「这段没有需要改的地方」这个意思、没有为了显得干了活而改一处、没有把原文换一种说法重抄一遍当成重讲。

## 怎么跑

1. 按 ENV-1 把 `plugin/skills/plain-language/` 整套（`SKILL.md` 与 `rules.md`）当作使用者机器上装好的这门技能交给 agent。本批用的是 skill-up：它把技能装到工作区的 `.claude/skills/plain-language/`，工作区根就是 ENV-6 那处临时目录。
2. 发下面那条用户消息（DATA-11，见下面的保真度折扣）。
3. 按 ENV-2 取这一轮的回复；按 `graders/no-forced-changes.md`（ENV-3）判。

用户消息（DATA-11 加上 DATA-6 的全文。**这里有一步保真度折扣**：`DATA-11` 原样是 `/shared-skills:plain-language 这段我看不懂，重讲一遍`，而 DATA-6 该作为 agent 的上一条回答在上下文里；本批用的是 skill-up，它的多轮只收 `user` 角色，塞不进一条 `assistant` 消息，所以把 DATA-6 的全文接在了这条用户消息里。见实施方案 2.1 第 5 小节第 3 条）：

```
/plain-language 这段我看不懂：

这次改动我梳理了一下。

现在这套检查有个盲区：文档里的表格没人管。链接对不对、标题层级顺不顺，`10-links.sh` 与 `20-headings.sh` 各管一样，但表格的行列数对不上，整套检查跑完也不会报。

补的办法是在 `checks/verify.d/` 下面加一个模块，名字叫 `30-tables.sh`，文件名的数字决定它排在最后跑。这个模块只做一件事：把每张表的行列数数一遍，对不上的报出来。

新模块的边界也说清楚：它只管表格。链接和标题层级仍旧由原来那两个模块管，不要重复检查。

写完跑一次 `bash checks/verify.sh`，输出的最后一行会列出这次一共跑了几个模块。看到三个，就说明新模块被认出来了。

重讲一遍
```

## 基线证据

**跑过七次，只过一次。这一条现在不过。**

| 摆法 | 次数 | 结果 |
|:---|:---|:---|
| 出货的摆法（DATA-6 接在用户消息里） | 4 | 0 过 4 挂 |
| 换措辞：用户消息写成「你上一条回答我看不懂」 | 3 | 0 过 3 挂 |
| 探针：让那段文字**真的**成为上一条回答（两轮） | 3 | 1 过 2 挂 |

挂的那些，产出都是同一路货色：把没问题的句子逐处同义替换。举两例原话——「这次改动我梳理了一下。」改成「这次改动，我重新理了一遍。」（连第一句都动）；「文档里的表格没人管」改成「文档里有个地方没管到」／「漏了一样东西」／「漏了一块」。判官每次都是逐句对照之后判的，不是误判。

**查过的两条道，都排除或部分排除了：**

1. **不是措辞的毛病。** 把用户消息换成 TC-4 那句「你上一条回答我看不懂」、让「这段」明确指回上一条回答——三跑三挂，一模一样。
2. **折扣占一部分，但不是全部。** 让 agent 第一轮把那段文字原样复述一遍、第二轮才说「这段我看不懂，重讲一遍」，那段文字就**真的**是它自己的上一条回答，实施方案 2.1 第 5 小节第 3 条那处折扣被绕开了。这一摆法**三跑一过**——说明摆对了它做得到，但也只有三分之一的时候做得到。

**所以这一挂的账要分两半记**：一半是摆法的折扣（100% 挂 vs 67% 挂），一半是真的行为缺口——`SKILL.md` 里「原文没问题就说『这段没有需要改的地方』，不硬凑」那句写着，但它只有约三分之一的时候照做。

**还没动的地方**：出货的 `tp07` YAML 仍是「接在用户消息里」这一摆法（单轮），没改成探针那个两轮版。改不改是设计决定——规格里 TC-5 的前置条件本来写的就是「按 DATA-6 把那段文字作为 agent 的上一条回答放进上下文」，两轮版才是照规格摆的，单轮版是折扣；但改成两轮要多一轮、多一次模型调用，且第一轮的复述未必逐字。三个探针文件存在仓库外：`C:/work/plain-language-eval-results/_probes/`。
