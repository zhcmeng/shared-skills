# 评测用例：引文本身一字不动，后面补中文

## 这条用例防的是什么

`rules.md` 把引文单独列了一条：引文不论长短，本身一字不动；后面补中文。成句成段的逐句对照——每句原句后面紧跟该句的中文；标题、章节名这类当标签用的名字，本身不动，后面用一个中文短语指认它说的是什么。

这条规则跟「改掉那几类问题」是**顶着的**：引文里照样可能有夹英文、有生造词，按前一条该改，按这一条一个字都不能碰。正确做法是引文原样留着，问题在引文外面补一句说明。要防的是两种省事的做法：把引文里的问题直接在引文里改掉（改了别人的话），或者干脆不管引文（读者还是读不懂）。

这一条钉四件事：成句引文逐句对照、当标签的标题后面有中文指认、引文里的问题在引文外补说明、引文元数据一个字没动。

## 怎么跑

1. 按 ENV-1 把 `plugin/skills/plain-language/` 整套（`SKILL.md` 与 `rules.md`）当作使用者机器上装好的这门技能交给 agent。本批用的是 skill-up：它把技能装到工作区的 `.claude/skills/plain-language/`，工作区根就是 ENV-6 那处临时目录。
2. 样本按 DATA-2 摆在工作区里 `evals/plain-language/cases/tp02-01-TC-2-quotes_kept_and_glossed/fixture/样本.md`（ENV-4）。这份文档里有一段五句的英文引文、一个当标签用的英文标题、一段带问题的中文旧稿引文、一处引文元数据。原始样本在仓库里同一个路径下，全程不动。
3. 发下面这条用户消息（DATA-8）。
4. 按 ENV-2 取这一轮的回复，以及那份样本在跑前跑后的差别；按 `graders/quotes-untouched.md`（ENV-3）判。

用户消息（DATA-8。规格里写的是 `/shared-skills:plain-language`，真跑时渲染成 `/plain-language`，见实施方案 2.1 第 5 小节第 1 条）：

```
/plain-language 这份文档里引了几段英文，我看着费劲，帮我改一下：evals/plain-language/cases/tp02-01-TC-2-quotes_kept_and_glossed/fixture/样本.md
```

## 基线证据

跑过一次（`batch3-full` 运行一，2026-09-29）：**1 次 1 过**（判 8/8）。

回复原话：「改好了：引文本身一字未动，缺的中文补在了引文外面。」

盘上 `workspace.diff` 只有 1 处改动：在中文旧稿那段引用块**后面**补了一句「这里的 decision journey，指的是读者从第一次接触到最后做决定的整个过程。」——引用块本身没进 diff，英文引文那五句与引文元数据也没进 diff。这条用例要防的两件事都没发生：没改引文，也没不管引文。
