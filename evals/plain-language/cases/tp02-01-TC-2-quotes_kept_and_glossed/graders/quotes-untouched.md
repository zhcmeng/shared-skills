# 判据：引文一个字没改，中文补在引文外面

只看 agent 这一轮的回复，以及那份样本在跑前跑后的差别。

样本里有两处引文，判法不一样：

- **英文引文那一段**（五句，正文里逐句写着中文）。它已经是对照好的样子——原句一行、中文一行，交替排下来。这一处的判定是：**原句五行一字未动，每句后面仍旧跟着它自己的那句中文**，中文是哪一句、在不在原位。
- **中文旧稿那一段**（一段引用块，里面有「心智物理」「信息势能」「认知对齐」与一个英文短语）。这一处的判定是：**引用块里面一个字没动**，问题在引用块外面补了说明。

另有两处照原样写的：一个英文标题，一处引文元数据（作者、出处、年份那一行）。

## 不通过

出现下面任何一条，就是不通过：

——英文引文的原句里，有任何一句被改了：换了词、删了从句、改了大小写或标点；

——英文引文的中文对照被打乱：中文跑到别的句子下面去了、某一句没有中文、中文被合并成一段；

——中文旧稿那段引用块里面被动过（引文里的「心智物理」「认知对齐」或那个英文短语被改掉、被加注在引文内部）；

——引用块外面没有补说明，读者仍然不知道里面那几个词是什么意思；

——引文元数据那一行被改了（作者名译成中文、年份格式变了、出处被改写）；

——那个英文标题被删掉、被译掉，或者后面没有中文短语指认它说的是什么。

## 通过

英文引文原句五行一字未动、每句后面跟着自己的中文；中文旧稿那段引用块里面一字未动、外面补了一句说明；英文标题本身留着、后面有一个中文短语指认；引文元数据一字未动。

## 判的时候留个心

——**「补说明」补在哪都行**：紧跟引用块后面另起一段最自然，写在引用块上一段也认。要求是读者能看出「这一段是在解释上面引用块里的说法」，不要求固定位置。

——**中文对照可以照抄前面已有的**：样本里英文引文的中文本来就写好了，agent 原样留着算对；把中文润色一遍但意思不变，也算对。不许的是把原句动了。

——**当标签用的标题，中文指认写成什么样不限**：「怎么把一段含糊的话改清楚」或者「（意思是：怎么写清楚一段话）」都算。要求是后面有一个中文短语，且标题本身没动。

——**别的句子照旧该改**：这条用例只管引文与元数据那几处。文档里引文之外的正文如果有那几类问题，改掉才对，不算违反这一条。样本里引文之外的问题句不多，看到改了不要判成「动多了」。

——**取不到前后差别时**（差集为空、或被判成省略了）：不要因此判不通过。工作区是一个 git 仓库，跑前的状态已经提交成一条基线，直接 `git status --porcelain -uall` 与 `git diff` 就能看出改了什么；对不上的地方再读一遍文件本身。

——**工作区里的 `.claude/skills/plain-language/` 那两条删除不是 agent 干的**：skill-up 在判官开跑前会把装进去的技能副本删掉。看到这两条，不要算到「样本之外的文件被动过」头上。
