# 测试规程规格说明

测试项：`plugin/skills/plain-language/` 整门技能。八条测试用例各占一条测试规程——一条规程一条用例，每条自包含：读那一条就能把它的前置条件摆全、跑起来、收尾，不必读文档别处。规程的次序按原来那一档的次序排下来，同档之内风险等级高的在前。

## TP-1 逐处处置：该改的与不该动的

| 唯一标识符 | TP-1 |
|:---|:---|
| 英文名 | fix_only_what_should_change |
| 目标 | 把「给一个文件路径、逐句审并直接改原文件」这一档走一遍：一份混合文档里既有该改的、也有照原样写的，改完之后该改的都被改掉、不该动的一个字没动。 |
| 风险等级 | 高 |
| 执行器 | 子代理（要另起一个会话：把技能整套交给它、发一条用户消息、取回复与盘上的改动） |
| 改动文件 | 会写（跑 TC-1 时 agent 会写盘——写的是样本副本；技能目录本身一个字不动） |
| 启动 | 按 ENV-1 把 `plugin/skills/plain-language/` 整套交给 agent，工作目录设在本仓库根；按 DATA-1 备一份可写的样本副本，DATA-7 那条消息里的路径指向这份副本；按 ENV-3 读 `graders/only-problems-touched.md`；按 ENV-4 把副本摆在可写工作区里；按 ENV-2 取 agent 当轮的回复，以及被改动的那份文件在跑前跑后的内容；会话在 ENV-6 那处起、收，副本落在 ENV-7 那处。 |
| 有序执行测试用例 | TC-1 |
| 与其他规程的关系 | 与其余七条互不依赖，先后都可以。 |
| 停止与结束 | 把样本副本按 DATA-1 的重置需求复位成原样；核对 `plugin/skills/plain-language/` 没有被改动过。 |
