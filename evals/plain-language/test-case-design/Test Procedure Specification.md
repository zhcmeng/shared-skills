# 测试规程规格说明

测试项：`plugin/skills/plain-language/` 整门技能。八条测试用例排成三条测试规程，排的顺序按用例之间的前置条件依赖：给文件路径那一档的五条排成 TP-1，无参数重说那一档的两条排成 TP-2，常驻注入那一档的单条排成 TP-3。每条规程的「有序执行测试用例」栏里，风险等级高的用例排在同组前面；同一等级内按样本编号的顺序排。

## TP-1 逐处处置：该改的与不该动的

| 唯一标识符 | TP-1 |
|:---|:---|
| 英文名 | fix_what_should_change |
| 目标 | 把「给一个文件路径、逐句审并直接改原文件」这一档走一遍：一份混合文档（该改的与不该动的都在里面）、一份引文文档、一份审的范围文档（含一个代码块）、一份一处问题都没有的文档，以及一个改不动的路径。 |
| 风险等级 | 高 |
| 执行器 | 子代理（每条用例要另起一个会话：把技能整套交给它、发一条用户消息、取回复与盘上的改动） |
| 改动文件 | 会写（跑 TC-1、TC-2、TC-3 时 agent 会写盘——写的是样本副本；技能目录本身一个字不动） |
| 启动 | 按 ENV-1 把 `plugin/skills/plain-language/` 整套交给 agent，工作目录设在本仓库根；按 ENV-4 把 DATA-1 至 DATA-4 那四份样本各备一份副本；TC-7 那条消息（DATA-13）里指的路径本来就不存在，不用另摆；ENV-3 的判据文件各就位。这一条在 ENV-6 那处（WSL2）里起会话；盘上的样本副本就在 ENV-7 那处（本机 Windows），按 WSL2 的挂载路径指过去。 |
| 有序执行测试用例 | TC-1、TC-2、TC-3、TC-6、TC-7 |
| 与其他规程的关系 | 与 TP-2、TP-3 没有依赖，先后都可以。 |
| 停止与结束 | 把四份样本副本复位成原样（TC-1 至 TC-3 改过它们）；核对技能目录 `plugin/skills/plain-language/` 没有被改动过。 |

## TP-2 无参数重说

| 唯一标识符 | TP-2 |
|:---|:---|
| 英文名 | restate_last_answer |
| 目标 | 把「无参数时把最近产出的那条回答整条重讲一遍」这一档走一遍：上一条回答有那几类问题的、和一处问题都没有的。 |
| 风险等级 | 高 |
| 执行器 | 子代理 |
| 改动文件 | 只读（这一档只产出文字，规程执行当中不动盘上任何东西） |
| 启动 | 按 ENV-1 把技能整套交给 agent，工作目录设在本仓库根；按 DATA-5、DATA-6 把那两段文字分别作为 agent 的上一条回答放进上下文；ENV-3 的判据文件各就位。这一条同样在 ENV-6 那处（WSL2）里跑；这一档不动盘，ENV-7 那处只放会话的工作目录。 |
| 有序执行测试用例 | TC-4、TC-5 |
| 与其他规程的关系 | 与 TP-1、TP-3 没有依赖。 |
| 停止与结束 | 关掉这两轮会话；盘上不需要复位，这一档没有写盘动作。 |

## TP-3 常驻注入之下直接写东西

| 唯一标识符 | TP-3 |
|:---|:---|
| 英文名 | ambient_rules_writing |
| 目标 | 把「`rules.md` 注进上下文之后、不经 skill 直接写东西」那一条路走一遍。 |
| 风险等级 | 中 |
| 执行器 | 子代理 |
| 改动文件 | 只读（产出的是回复文本，规程执行当中不动盘上任何东西） |
| 启动 | 按 ENV-5 把 `rules.md` 按 SessionStart hook 的做法注入上下文；这一档不把技能当作被调用的技能交给 agent——用户消息（DATA-14）里不带技能名；按 ENV-2 取当轮的产出文本。这一条同样在 ENV-6 那处（WSL2）里跑；这一档不动盘（ENV-7 只放会话的工作目录）。 |
| 有序执行测试用例 | TC-8 |
| 与其他规程的关系 | 与 TP-1、TP-2 没有依赖；这一条的跑法与那两条不同（不经 skill），单独成一条。 |
| 停止与结束 | 关掉这轮会话。 |
