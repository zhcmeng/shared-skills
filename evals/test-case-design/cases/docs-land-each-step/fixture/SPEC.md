# slugify 需求说明

`slugify.py` 把一段标题转成 URL 短名，供生成页面文件名使用。

## 用法

命令行提供一个参数：

    python slugify.py "标题文本"

输出一行：处理后的短名。不提供参数时打印用法提示并以非 0 状态结束。

## 转换规则

按顺序处理：

1. 去掉首尾空白；
2. 全部转小写；
3. 连续空白折成一个连字符 `-`；
4. 去掉除字母、数字、下划线、连字符以外的字符。

规则 2 只在 ASCII 上生效；中文没有大小写之分，保持原样。

## 口径与边界

- 转换规则以本说明为准；同一段标题每次转换结果必须一致。
- 输入为空字符串或只有空白时，输出空行。
- 只处理单行标题；标题里出现换行时按空白处理。
