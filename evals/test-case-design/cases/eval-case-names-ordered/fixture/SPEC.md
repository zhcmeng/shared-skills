# 需求：文件名短名化技能

做一个技能，用户说「把这批标题转成文件名」时照下面的规矩办。

## 一、脚本行为

技能目录下有一个 `slug.py`：

1. `slug.py "<标题>"`：打印短名，退出码 0。大写字母转小写、空格与下划线换成连字符、其余标点去掉、首尾多余的连字符合并后去掉。
2. 标题里除了字母数字与上面那几类之外什么都没有时，输出空行，退出码 0。
3. 标题里出现连续多个空格时，输出里只有一个连字符，不出现 `--`。
4. 没给参数时退出码 1，标准错误里给出用法。

## 二、技能行为

5. 用户一次给多个标题时，逐个转换、一行一个结果；不把结果拼成一行。
6. 转换结果里出现了 `--` 或首尾多余的连字符时，**不自行修正后照常输出**，而是把原始输出与那条规矩一起报给用户，让他定。
7. 用户没给标题时反问一句「哪些标题」，不自己编一个样例跑给他看。
