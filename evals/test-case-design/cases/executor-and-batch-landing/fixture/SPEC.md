# 需求：临时文件整理技能

做一个技能，用户说「把 X 目录里的临时文件清掉」时照下面的规矩办。

## 一、脚本行为

技能目录下有一个 `tidy.py`：

1. `tidy.py --list <目录>`：列出该目录下后缀是 `.tmp` 或 `.bak` 的文件，每行一个，退出码 0。
2. `tidy.py --clean <目录>`：删掉这些文件，打印「删了 N 个」，退出码 0。
3. 目录不存在时，两条命令都退出码 1，标准错误里写明那个路径。
4. 参数不对（没给子命令、没给目录、子命令不认识）时退出码 2，标准错误里给出用法。

## 二、技能行为

5. 用户说了目录时才动手；没说目录时**不能自己猜一个**，要先反问一句「哪个目录」再等回答。
6. 用户说了目录、但那个目录不存在时，把脚本的标准错误原样转述给用户，不自己另编一句。
7. 删之前先把 `--list` 的结果报给用户看一遍，等用户确认再 `--clean`。
