# 测试环境需求

执行三条测试规程所需的环境要素，逐项列出。

| 唯一标识符 | 测试环境项 | 描述 |
|:---|:---|:---|
| ENV-1 | Python 解释器 | CPython 3.9 及以上，Windows x64。打包的 wheel 只覆盖这个平台，靠它离线安装那条路（TC-17）也只有在这类机器上才走得通；换到别的平台或架构上，测试项会直接落到联网安装，TC-17 就不再成立 |
| ENV-2 | DeepSeek 官方词表文件 | `tokenizer.json`，随技能分发的那一份，与官方离线包里的同一份（执行前核对内容一致）。测试项的计数结果全部以这份文件的规范语义为准 |
| ENV-3 | 打包的引擎 wheel | `tokenizers-0.22.2-cp39-abi3-win_amd64.whl`，放在技能目录的 `wheels/` 下 |
| ENV-4 | 技能目录的一份可写副本 | 可以在副本上把 `wheels/` 下的文件移走或换成坏文件，不动原始技能目录 |
| ENV-5 | 可以反复新建的干净 Python 环境 | 没有安装 `tokenizers` 的环境，临时虚拟环境即可；每换一条涉及安装的用例都要重新建一个 |
| ENV-6 | 能访问软件源的网络出口 | 能连到 PyPI，供联网安装那条路使用 |
| ENV-7 | 完全不能对外联网的运行条件 | 可以用本来就没有网络出口的环境，或在运行期间切断网络来造 |
| ENV-8 | 命令行外壳，带管道与重定向能力 | 三条输入通道里的标准输入通道要用它接上 |
| ENV-9 | 能分别取得标准输出、标准错误与退出码的执行方式 | 多条用例的判定要看这三样：标准输出上的两行、标准错误上有没有提示、进程以什么状态结束 |
