# 决策依据

本文件记的是这份测试用例设计的过程。其余五份记结论——模型长什么样、覆盖项有哪些、用例怎么导的；这一份记每一处当时摆着哪几种做法、凭什么取了这一种。一条一行，按定下来的先后排。这份分两块写：先是「用户决策」（**可以直接改**），再是「模型决策」（**只增不改**——后面发现前面定错了，新加一条写明订正的是哪一条，原来那条留着）。

测试项是 `plugin/skills/token-counter/scripts/count_tokens.py`（下称测试项），是一段命令行脚本：用随包的 DeepSeek 官方词表算一段文本或一个文件有多少个 token。测试依据取自同目录的 `SKILL.md`（用法、口径与边界）、脚本本身，以及随包的官方词表文件。

上面这一段是 DEC-1 至 DEC-21 那一轮写下的，那一轮只做脚本层，测试项就是那个脚本。第二轮往同一套产出里补了本体层：测试项扩到整门技能，多加两个模型（TM-6、TM-7）、9 条覆盖项、8 条用例与一条规程，DEC-22 起记的是那一轮。那段写照留着不动——它说的是第一轮当时的情形。
