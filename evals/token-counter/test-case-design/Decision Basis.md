# 决策依据

本文件记的是这份测试用例设计的过程。其余五份记结论——模型长什么样、覆盖项有哪些、用例怎么导的；这一份记每一处当时摆着哪几种做法、凭什么取了这一种。一条一行，按定下来的先后排。这份分两块写：先是「用户决策」（**可以直接改**），再是「模型决策」（**只增不改**——后面发现前面定错了，新加一条写明订正的是哪一条，原来那条留着）。

测试项是 `plugin/skills/token-counter/` 整门技能。它由一份技能正文（`SKILL.md`）和一支计数脚本（`scripts/count_tokens.py`）组成：技能正文管「什么时候用、怎么答、口径与边界」，脚本用随技能分发的那份官方词表按规范语义数 token，报出 token 数与字符数两行。技能还随包带着两样东西——官方词表 `tokenizer.json` 与引擎的安装包 `wheels/`，首次在没装引擎的目标机上运行时自动装上。它靠模型驱动着跑：技能被唤起后，模型照正文把脚本调起来。测试依据取自这两份文件，见测试模型规格说明文末的「依据 → 模型」对应表。
