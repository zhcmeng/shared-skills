# 测试规程规格说明

三条测试规程，把 21 条测试用例按前置条件与风险排好顺序。风险高、优先级高的用例排在各自规程的前面。

## TP-1 在装好引擎的机器上把常规计数跑一遍

**唯一标识符**：TP-1

**目标**：用命令行、文件、标准输入三条通道各数几遍，把计数口径与三种输入来源钉住。

**优先级**：高（本规程里有 8 条高优先级用例，计数口径那部分全在这里）。

**启动**：确认机器上 `tokenizers` 可以导入；确认测试项与随技能分发的词表文件在位；按测试数据需求备好样本（DATA-1 至 DATA-10、DATA-15、DATA-17）；确认命令行能接管道与重定向，并能分别取到标准输出、标准错误与退出码。

**有序执行测试用例**：

1. 执行 TC-1
2. 执行 TC-2
3. 执行 TC-9
4. 执行 TC-10
5. 执行 TC-14
6. 执行 TC-6
7. 执行 TC-16
8. 执行 TC-21
9. 执行 TC-7
10. 执行 TC-11
11. 执行 TC-12
12. 执行 TC-13
13. 执行 TC-15

顺序允许变动的程度：高优先级的那几条（第 1 至 8 步）之间可以互换，中优先级的那几条（第 9 至 13 步）之间可以互换；中优先级的用例不得排到高优先级用例之前。用例之间没有依赖，不需要在两条之间补准备动作。

**与其他规程的关系**：与 TP-2 无依赖，两条可以任意先后。TP-3 在自己的临时环境里跑，不改变本规程所在机器的状态，因此也可任意先后。

**停止与结束**：删除本次为核对用例生成的临时文件（如果有）；环境不需要复位。

## TP-2 把无效输入那几条跑一遍

**唯一标识符**：TP-2

**目标**：确认无效输入不给计数结果、以非 0 状态结束，且不被当作空正文数出 0 个 token。

**优先级**：中（本规程里全是中优先级用例）。

**启动**：用与 TP-1 相同的机器即可，不需要为引擎状态做特别准备（无效输入在计数之前就被拦下）；备好样本 DATA-11、DATA-12、DATA-13、DATA-14。

**有序执行测试用例**：

1. 执行 TC-3
2. 执行 TC-4
3. 执行 TC-5
4. 执行 TC-8

顺序允许变动的程度：四条之间可以任意互换，彼此无依赖。

**与其他规程的关系**：与 TP-1 无依赖；与 TP-3 无依赖。

**停止与结束**：无收尾动作。

## TP-3 在干净环境上把引擎首次就绪的三条路径跑一遍

**唯一标识符**：TP-3

**目标**：把首次运行自动装引擎的几条路逐一走通：靠打包 wheel 离线装成、wheel 不在时转联网、wheel 装不上时转联网、两条路都不通时终止。

**优先级**：高（前三条用例是高优先级）。

**启动**：建一个没有安装 `tokenizers` 的 Python 环境；把技能目录复制一份可写副本，副本的 `wheels/` 下放好打包 wheel；备好样本 DATA-1、DATA-2 与坏 wheel（DATA-16）；确认网络可以按需切断与恢复。

**有序执行测试用例**：

1. 切断对外网络；执行 TC-17
2. 复位：另建一个干净环境（未装引擎），恢复网络
3. 把副本 `wheels/` 下的 wheel 移走；执行 TC-18
4. 复位：另建一个干净环境；把可用的 wheel 放回，再换成同名的坏文件
5. 执行 TC-19
6. 复位：另建一个干净环境；把坏文件也移走（使 wheel 不在）；切断对外网络
7. 执行 TC-20

顺序允许变动的程度：第 1 步与第 3 步可以互换；第 7 步（中优先级）不得排到前面三条之前。每两条之间必须按上面写的复位步骤把环境恢复成「未装引擎」——前一条跑完会把引擎留在环境里，不复位后一条就落在另一个状态上。

**与其他规程的关系**：与 TP-1、TP-2 无依赖，可任意先后；本规程全程使用自己的临时环境与技能目录副本，不动原技能目录，也不改所在机器的引擎状态。

**停止与结束**：删除临时环境与技能目录副本；恢复被切断的网络；确认原技能目录未被改动。
