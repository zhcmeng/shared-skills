# 测试规程规格说明

测试项是 `plugin/skills/token-counter/` 整门技能。四个测试规程按判据落在哪分两批：TP-1、TP-2 的判据落在命令的输出、退出码与盘上落下的文件上，跑一遍就有结论；TP-3、TP-4 的判据要读模型跑起来一路做了什么。

规程里凡用到测试环境或测试数据要素，按 `ENV-`、`DATA-` 编号指代，内容在测试环境需求与测试数据需求那两份里。

## TP-1 计数的三道输入与文本取值

| 唯一标识符 | TP-1 |
|:---|:---|
| 英文名 | count_routes_and_text_values |
| 目标 | 把三条输入道、各类文本取值、字节层面的边界值与几处走不通的收场，按命令行跑一遍。 |
| 风险等级 | 高 |
| 执行器 | 脚本 |
| 改动文件 | 只读 |
| 启动 | ENV-1、ENV-2 就位；ENV-3 的技能副本摆到盘上；确认 ENV-4 的解释器能导入那份引擎；按 DATA-1 至 DATA-14 在 ENV-8 里把样本摆好（DATA-9 至 DATA-11 是直接交给命令行的文字，不用落成文件）；确认 ENV-8 里没有 `not_here.bin` 这个文件。 |
| 有序执行测试用例 | 1. TC-1；2. TC-2；3. TC-3；4. TC-4；5. TC-5；6. TC-6；7. TC-7；8. TC-8；9. TC-9；10. TC-10；11. TC-11；12. TC-12；13. TC-13；14. TC-14；15. TC-15；16. TC-16；17. TC-17；18. TC-18；19. TC-19；20. TC-20；21. TC-21 |
| 与其他规程的关系 | 无。它是本套里的第一条，跑完再跑 TP-2。 |
| 停止与结束 | 把 ENV-8 里的样本清掉。规程执行当中只读测试项，不必复位。 |

## TP-2 首次运行的安装道

| 唯一标识符 | TP-2 |
|:---|:---|
| 英文名 | first_run_install_paths |
| 目标 | 把判定表四条规则各跑一遍：引擎已在位不装、干净机器装打包那份、打包那份装不上改走联网、打包那份不在直接走联网。 |
| 风险等级 | 中 |
| 执行器 | 脚本 |
| 改动文件 | 只读 |
| 启动 | 先跑完 TP-1；按 ENV-5 备好干净解释器并确认它导不进那份引擎；把 ENV-3 的副本复制两份到 ENV-8（一份原样、一份把 `wheels/` 里那份包换成同名的坏文件、一份删掉 `wheels/` 目录——共三份，只改后两份）；确认 ENV-6 可达。 |
| 有序执行测试用例 | 1. TC-22；2. TC-23；3. TC-24；4. TC-25 |
| 与其他规程的关系 | 在 TP-1 之后执行。与 TP-3、TP-4 互不相干，先后不限。 |
| 停止与结束 | 把 ENV-8 下那几份副本删掉；把 ENV-5 那个解释器整个删掉重建——里面装上了引擎，别留给下一批用。 |

## TP-3 技能层的常规场景

| 唯一标识符 | TP-3 |
|:---|:---|
| 英文名 | skill_layer_scenarios |
| 目标 | 把整条链串起来跑：唤起、按正文调用脚本、把结果答回；含点名别的模型、问调用成本、完整对话请求、只要 token 量、特殊 token、两处走不通的收场。 |
| 风险等级 | 中 |
| 执行器 | 控制器 |
| 改动文件 | 只读 |
| 启动 | ENV-1、ENV-2 就位；ENV-3 的技能按使用者机器上装好的样子在一个模型会话里就位；ENV-7 的过程记录开着；按 DATA-2 与 DATA-14 在 ENV-8 里把文件摆好；确认 ENV-8 里没有 `not_here.bin`。 |
| 有序执行测试用例 | 1. TC-26；2. TC-27；3. TC-28；4. TC-29；5. TC-30；6. TC-31；7. TC-33；8. TC-34；9. TC-35 |
| 与其他规程的关系 | 与 TP-1、TP-2 互不相干；与 TP-4 串着跑，TP-3 在前、TP-4 在后（两条共用同一个会话）。 |
| 停止与结束 | 会话结束，把 ENV-8 里这一批用过的样本清掉。规程执行当中只读测试项，不必复位。 |

## TP-4 技能层的干净机器那一条

| 唯一标识符 | TP-4 |
|:---|:---|
| 英文名 | skill_layer_clean_machine |
| 目标 | 目标机没装引擎时，把整条链串起来跑一遍：首次运行把引擎装上，再照常报数。 |
| 风险等级 | 中 |
| 执行器 | 控制器 |
| 改动文件 | 只读 |
| 启动 | 先跑完 TP-3；按 ENV-5 备好干净解释器，并把它当这一轮会话里默认的 `python`；按 DATA-2 在 ENV-8 里把文件摆好；ENV-7 的过程记录开着。 |
| 有序执行测试用例 | 1. TC-32 |
| 与其他规程的关系 | 在 TP-3 之后执行（两条共用同一个会话，它要换掉会话里的解释器）。 |
| 停止与结束 | 会话结束；把 ENV-5 那个解释器删掉重建；清掉 ENV-8 里的样本。 |

注：四条规程都标「只读」，是因为测试项本身在跑的过程中没被改动——它是离线脚本，跑一次只读词表、往标准输出吐两行。TP-2 里那几份被改过的副本、ENV-5 里装进去的引擎，都是为跑规程搭的场子（摆样本、建夹具那一类），不算改动测试项，照规矩写在「启动」与「停止与结束」两栏里。
