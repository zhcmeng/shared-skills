# 测试规程规格说明

测试项：`plugin/skills/token-counter/scripts/count_tokens.py`。26 条测试用例排成四条测试规程，排的顺序按用例之间的前置条件依赖：同一个环境状态的用例排在同一组，涉及安装的四条单独放最后一条。每条规程的「有序执行测试用例」栏里，风险等级高的用例排在同组前面；同一等级内按输入通道与样本编号的顺序排。

## TP-1 主场景与三条输入通道

| 唯一标识符 | TP-1 |
|:---|:---|
| 目标 | 在已经装好引擎的机器上，把三条输入通道各走一遍：给文件路径（主场景）、给字面文本、接标准输入，以及空管道那一种。 |
| 风险等级 | 高 |
| 启动 | ENV-1 那台机器就位，按 ENV-2、ENV-3 确认词表与 wheel 在位，并确认引擎已经可以导入——本规程不装任何东西；ENV-4 工作区里按 DATA-1 备好那段正文的三个副本（`--text` 用的字面文本、一个不带编码标记的文件、一份接到标准输入用的字节），按 DATA-9 备好那份 Markdown 文件；ENV-8 的管道与重定向可用。 |
| 有序执行测试用例 | TC-26、TC-1、TC-16、TC-5 |
| 与其他规程的关系 | 无。本规程跑完后跑 TP-2。 |
| 停止与结束 | 删掉本规程用到的样本文件；本规程不装、不卸任何东西，环境保持原样。 |

## TP-2 正文内容与计数口径

| 唯一标识符 | TP-2 |
|:---|:---|
| 目标 | 把正文内容的各等价类各跑一遍，并钉住 `chars` 的口径与两条通道之间的一致性。 |
| 风险等级 | 高 |
| 启动 | ENV-1 那台机器就位，引擎已经可以导入；ENV-4 工作区里按 DATA-2 至 DATA-8、DATA-10、DATA-17 备好各条要用的正文与文件。 |
| 有序执行测试用例 | TC-2、TC-3、TC-4、TC-9、TC-15、TC-10、TC-6、TC-7、TC-8 |
| 与其他规程的关系 | 在 TP-1 之后执行——TP-1 已经把这台机器与工作区摆好，本规程接着用。 |
| 停止与结束 | 删掉本规程用到的样本文件；本规程不动环境。 |

## TP-3 无效输入与边界值

| 唯一标识符 | TP-3 |
|:---|:---|

| 启动 | ENV-1 那台机器就位，引擎已经可以导入；ENV-4 工作区里按 DATA-11 至 DATA-16 逐字节造好样本文件，并先建好一个空目录；ENV-8 的管道可用。 |
| 有序执行测试用例 | TC-11、TC-12、TC-13、TC-14、TC-17、TC-18、TC-19、TC-20、TC-21 |

## TP-4 引擎就绪路径

| 唯一标识符 | TP-4 |
|:---|:---|
| 目标 | 把引擎从哪来的四条路走一遍：离线装随包 wheel、wheel 装不上转联网、没有 wheel 直接联网、两条路都不通时终止。 |
| 风险等级 | 中 |
| 启动 | ENV-4 里另存一份技能目录的副本，`wheels/` 下放着 ENV-3 那个 wheel；按 ENV-5 新起一个没装引擎的干净环境——本规程每条用例各起一个新环境，不共用；ENV-6 与 ENV-7 两种网络条件按条切换。 |
| 有序执行测试用例 | TC-22、TC-23、TC-24、TC-25 |
| 与其他规程的关系 | 放在最后执行：这四条会往环境里装引擎，而前面三条规程都要求引擎已经装好、且全程不装任何东西。 |
| 停止与结束 | 删掉本规程新起的干净环境与那份技能目录副本；核对原始技能目录（含 `wheels/`）没有被改动过。 |
