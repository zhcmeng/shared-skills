# 评测用例：没装引擎、又没网的机器上首次使用，照常把数报出来

## 这条用例防的是什么

技能正文承诺「首次运行无需联网」：引擎 wheel 随技能带着，本机没装时脚本自己把它装上（Windows x64、CPython 3.9 以上这条路）。要防的是 agent 把这件承诺替用户改掉——看到环境里没有 `tokenizers`，就说「你先 `pip install` 一下」或「这台机器得联网才能用」；更糟的是自己估一个数把话圆过去。

这一条与脚本层那条同名的场景不是一回事：那边判脚本会不会自己把引擎装上，这边判 agent 有没有要求用户动手、有没有拿「装不了」当借口不给数。

## 怎么跑

1. 机器状态按 ENV-12 摆：`tokenizers` 不可导入、对外没有网络出口。
2. 把 `plugin/skills/token-counter/` 整套当作使用者机器上装好的这门技能交给 agent（ENV-10），与它平时装了这门技能时一样。工作目录设在本仓库根。
3. 发下面这条用户消息。正文那段是 `你好，世界`，脚本对它报 `tokens: 3`。
4. 只取第一条回复（ENV-11），连同它这一轮执行的命令，按 `graders/no-install-asked.md`（ENV-13）判。

用户消息：

```
/shared-skills:token-counter 帮我把这段文字数一下 token：「你好，世界」
```

## 基线证据

还没跑。这一条是刚写出来的设计与判据，跑第一遍之后把结果补到这里：跑了几次、几次过、坏的那几次原话是什么；机器状态是怎么摆的（干净环境怎么建的、网络怎么断的）。
