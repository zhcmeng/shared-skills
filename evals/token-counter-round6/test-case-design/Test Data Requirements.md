# 测试数据需求

一条数据项一行，写这四栏。表下是几条「正文见下面」的数据项的正文，段首标出编号。

| 唯一标识符 | 英文名 | 描述 | 重置需求 |
|:---|:---|:---|:---|
| DATA-1 | text_samples | 直接交到命令行上的几段文本，共 6 段：第 1 段纯 ASCII；第 2 段纯中文；第 3 段中英混排、含空格与换行；第 4 段以中文开头、中间带一个空格；第 5 段只有一个 ASCII 字符；第 6 段只有一个占四个字节的字符。六段的正文见下面。 | 不需要 |
| DATA-2 | empty_text | 空的文本，0 个字符，一个字节都不带。交过去时要写成显式的空串——不写成这样就与「什么可数的东西都没给」在消息上分不开。 | 不需要 |
| DATA-3 | special_token_literal | 含特殊 token 字面形的文本，正文见下面。那个字面形照原样用，不转义、不拆开、不剥离。 | 不需要 |
| DATA-4 | markdown_sample | 那份 .md 样本，正文见下面。字节按不带字节顺序标记的 UTF-8 存、末尾一个换行，整份 65 个字节、25 个字符。 | 不需要 |
| DATA-5 | empty_file | 一个 0 字节的文件，摆成当前目录下的 `empty.txt`。 | 不需要 |
| DATA-6 | stdin_sample | 走管道那份样本的正文，见下面。两行之间一个换行，整份 32 个字节、16 个字符。 | 不需要 |
| DATA-7 | bom_complete_sample | 开头带一个完整字节顺序标记的文件，摆成当前目录下的 `bom-complete.txt`。开头 3 个字节是 `EF BB BF`，后面接正文（正文见下面，末尾一个换行）；整份 37 个字节——正文那 34 个加开头标记的 3 个。 | 不需要 |
| DATA-8 | bom_plus_one_sample | 开头 3 个字节之后紧接一个字节、再接正文的文件，摆成当前目录下的 `bom-plus-one.txt`。开头 3 个字节是 `EF BB BF`，第 4 个字节是小写字母 `a`，后面接与 DATA-7 同一段正文；整份 38 个字节、把开头那 3 个字节剥掉之后 13 个字符。 | 不需要 |
| DATA-9 | dead_end_targets | 走不通的两样：当前目录下一个不存在的名字 `no-such-file.md`；一个目录 `a-directory/`，里面摆一个占位文件，好让这一层目录进得了版本库。 | 不需要 |
| DATA-10 | gbk_sample | 按 GBK 写的那份文件，摆成当前目录下的 `gbk-sample.txt`，27 个字节，字节见下面——有意不存成 UTF-8。 | 不需要 |
| DATA-11 | full_dialogue_sample | 要当成一次完整对话请求来估的那段用户消息，正文见下面。 | 不需要 |
| DATA-12 | unusable_wheel_sample | 一份装不上的引擎包样本：文件名取成 `tokenizers-0.22.2-py3-none-any.whl`，内容不是一个包，正文见下面，19 个字节。它摆进技能副本的 `wheels/` 下，用来把「打包那份在、可它装不上」这一处条件凑出来。 | 不需要 |
