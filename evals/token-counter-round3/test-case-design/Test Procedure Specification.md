# 测试规程规格说明

## TP-1 脚本层的三种来路与输入取值

| 唯一标识符 | TP-1 |
|:---|:---|
| 英文名 | script_input_paths_and_values |
| 目标 | 把脚本层的三种来路、四组输入取值与两处长度边界按顺序跑一遍。 |
| 风险等级 | 中 |
| 执行器 | 脚本（跑命令、比标准输出那两行，不用模型） |
| 改动文件 | 只读 |
| 启动 | ENV-1、ENV-2、ENV-3 就位；按 DATA-1～DATA-12 把样本与正文备好，文件样本按原样放到 ENV-2 的一个临时工作目录里；确认技能目录下 `scripts/count_tokens.py`、`tokenizer.json` 都在。 |
| 有序执行测试用例 | TC-1、TC-2、TC-3、TC-4、TC-5、TC-6、TC-7、TC-8、TC-9、TC-10、TC-11、TC-12、TC-13 |
| 与其他规程的关系 | 与 TP-2、TP-3 没有先后依赖，可以同时执行；三者都要 ENV-1、ENV-2 就位。 |
| 停止与结束 | 十三条跑完即停；清掉为跑本条而建的临时工作目录，技能目录本身未被改动，不需要复位。 |

注：TC-4 与 TC-6 两条的预期结果不写取值（依据未规定这两处），跑的时候把实际输出照实记下来即可，判的是那两栏里写明的部分。

## TP-2 引擎获取的三条规则

| 唯一标识符 | TP-2 |
|:---|:---|
| 英文名 | engine_acquisition_rules |
| 目标 | 把引擎获取那张判定表的三条规则各跑一遍。 |
| 风险等级 | 高 |
| 执行器 | 脚本（跑命令、比标准输出与标准错误，不用模型） |
| 改动文件 | 只读 |
| 启动 | ENV-1、ENV-2 就位；ENV-3 与 ENV-4 各就位一个解释器——ENV-4 那个里面已经装好引擎；ENV-5 另起一个干净解释器，里面不装引擎；按 DATA-1 备好那段正文；按 DATA-6 在临时目录摆一份测试项副本，副本里不含随包的 wheel。ENV-6 确认网络出口可用。 |
| 有序执行测试用例 | TC-14、TC-15、TC-16 |
| 与其他规程的关系 | 与 TP-1、TP-3 没有先后依赖，可以同时执行。三条用例之间有先后要求：TC-15 跑完，ENV-5 那个解释器里就有引擎了，TC-16 必须在引擎还没装进去的时候跑，所以 TC-16 排在 TC-15 前面或另起一个干净解释器——本条按前者排。 |
| 停止与结束 | 三条跑完即停；ENV-5 那个解释器用完即删（里面已经被装上了引擎）；临时目录里的副本一并清掉；技能目录本身未被改动，不需要复位。 |

注：TC-16 走的是联网兜底那条规则。依据里那句规则写的触发条件是「平台不符（非 Windows x64 / CPython <3.9）」，在 ENV-3 那台机器上这个条件造不出来，所以这一条换一个能把脚本推到同一个动作上的触发条件——让随包的 wheel 不在。判据仍落在那个动作本身上（去 PyPI 装 `tokenizers==0.22.2`、装完照常报数），不落在触发条件上。这一处的取舍见决策依据。

## TP-3 技能被调用时的回话

| 唯一标识符 | TP-3 |
|:---|:---|
| 英文名 | skill_invocation_replies |
| 目标 | 把一条主场景加八条备选场景各跑一遍，看技能被调用之后回话里说了什么、有没有不该说的。 |
| 风险等级 | 高 |
| 执行器 | 子代理（要模型跑，而且要真去跑脚本、真去读盘上的文件） |
| 改动文件 | 只读 |
| 启动 | ENV-1 就位——测试规程在这一侧跑；ENV-2 就位——被测那侧在这一侧执行，技能已装进去；ENV-7 就位——执行过程读得回来；按 DATA-1、DATA-2、DATA-5、DATA-7、DATA-11、DATA-13 把正文与文件样本备好，文件样本按原样放到被测那侧读得到的工作目录里；ENV-5 另起一个干净解释器备用（TC-25 用）；ENV-6 确认网络出口可用。 |
| 有序执行测试用例 | TC-17、TC-18、TC-19、TC-20、TC-21、TC-22、TC-23、TC-24、TC-25 |
| 与其他规程的关系 | 与 TP-1、TP-2 没有先后依赖。本条内部九条用例之间没有前置依赖，次序可以调换；只有 TC-25 要在一个还没装引擎的解释器上跑，排在最后，跑之前确认 ENV-5 那个解释器里还没有引擎。 |
| 停止与结束 | 九条跑完即停；清掉被测那侧工作目录里为本条备下的文件样本；ENV-5 那个解释器用完即删。技能目录未被改动，不需要复位。 |

注：这一条九条用例的判据都落在「要读执行过程」那一层——除了回话里说了什么，还要看它是不是真去跑了脚本、跑的那一次给的是什么输入。所以这一条的执行器是子代理，落成的是评测用例，不是能跑的测试代码。
